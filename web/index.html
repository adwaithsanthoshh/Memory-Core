ALGORITHMIC MECHANICS

The Uncertainty-Aware DER++ Pipeline

Instead of uniform random sampling, MEMORYCORE evaluates every image's Cross-Entropy loss and selects the hardest decision boundary cases, combining this with Dark Experience Replay (logit preservation) for maximum knowledge retention.

PHASE 01 stream

Task Arrival

Sequential 64×64 RGB images from Split Tiny-ImageNet. 10 new classes per task, 20 total tasks (200 classes).

DIM: [B, 3, 64, 64]
PHASE 02 analytics

Uncertainty Scoring

Full forward pass over all task training images. Cross-Entropy loss computed per sample to measure prediction difficulty.

L_CE(x_i, y_i)
PHASE 03 sort

Selective Curation

Images ranked by loss descending. Top-K hardest boundary cases selected — not random. Only the most at-risk memories are kept.

argsort(L_CE)[::-1][:K]
PHASE 04 inventory_2

Logit Storage

Selected images stored with raw output logits ("dark knowledge") — the exact model confidence before forgetting begins.

Buffer: (x_i, y_i, z_i)
PHASE 05 psychology

DER++ Replay

Dual-objective gradient update: MSE distillation loss on stored logits + CE replay loss. Prevents catastrophic parameter overwriting.

α·MSE(z,z') + β·CE(y)
DER++ LOSS FORMULATION

Uncertainty-Weighted Continual Optimization

By storing the highest-loss exemplars (boundary cases where the model is most uncertain), the fixed memory budget is used maximally efficiently — capturing exactly the decision boundaries most vulnerable to catastrophic overwriting during subsequent task training.

TOTAL LOSS (α=0.5, β=1.0)
L = L_curr + α·MSE(f(x_m;θ), z_m) + β·CE(f(x_m;θ), y_m)

MEMORY ANALYSIS // BUDGET IMPACT ON CONTINUAL LEARNING

Memory Budget & Uncertainty Curation

How the fixed exemplar memory budget (M) affects final accuracy and forgetting — and why what you store matters more than how much.

What is Memory Budget?

The Memory Budget (M) is the maximum number of historical training images the continual learner is allowed to retain in storage across ALL previous tasks.

CAPACITY MATH · M=2000
2000 exemplars ÷ 20 tasks = 100 images/task boundary

For MemoryCore, these 100 images/task are NOT chosen randomly. They are the 100 with the highest Cross-Entropy loss — the hardest decision boundary cases that the model is most uncertain about.

For Random Replay, 100 images/task are chosen uniformly at random — no preference for hard or important cases.

Why MemoryCore Wins
By curating the hardest ~5% of samples (highest CE loss) rather than random 5%, MemoryCore squeezes dramatically more forgetting prevention from the same memory constraint. Decision boundaries are exactly what the model needs to remember — and exactly what's most vulnerable to catastrophic overwriting.
