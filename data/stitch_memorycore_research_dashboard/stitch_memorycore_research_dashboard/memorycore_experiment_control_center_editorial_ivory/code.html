Methodological Guarantees

The New Instances and Classes (NICv2-79) setting represents the most strenuous lifelong benchmark for object recognition. All strategies evaluated within MEMORYCORE are bound by identical memory budgets and batch ingestion cadences. MemoryCore’s gradient sensitivity gating ensures old task boundaries are preserved even under severe rehearsal bottlenecks.
